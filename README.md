# Projeto---Bomba-d-agua
Sistema embarcado com Arduino para monitorar e controlar o nível de água em reservatório de até 10m, com 5 níveis. Exibe dados em LCD 16x2 e aciona automaticamente a bomba. Simulado no TinkerCad com chaves e potenciômetro, registrando consumo para análise e redução de desperdícios.
